# 🎮 Steam Price Calculator - ماشین حساب قیمت بازی‌های استیم

<div dir="rtl">

## 📖 معرفی برنامه

نرم‌افزار **Steam Price Calculator** یک ابزار حرفه‌ای برای محاسبه قیمت بازی‌های استیم از ارز هریونیای اکراین "یا هر ریجن دیگری" به تومان ایران است. با استفاده از قیمت کلیدهای TF2 در بازار ایران، نرخ تبدیل را محاسبه کرده و قیمت نهایی بازی‌ها را نمایش می‌دهد.

</div>

---

## ✨ ویژگی‌های اصلی

<div dir="rtl">

| ویژگی | توضیح |
|-------|-------|
| 🎨 **۴ تم رنگی** | روشن، تیره، خاکستری و استیم (آبی تیره) |
| 🔄 **۳ حالت دریافت قیمت** | دستی، خودکار از سایت‌های پیش‌فرض، URL دلخواه |
| 📊 **جدول پیشرفته** | نمایش قیمت بازی‌ها با قابلیت افزودن و حذف |
| 💾 **ذخیره تنظیمات** | حفظ آخرین قیمت، تم انتخاب شده و ... |
| 🌐 **دریافت خودکار قیمت** | از سایت‌های wow-online، game4sell، gamerzshop |
| ⚡ **اجرای همزمان** | بدون هنگ کردن برنامه (Multi-threading) |
| 🔗 **لینک‌های قابل کلیک** | دسترسی سریع به شبکه‌های اجتماعی |

</div>
